# **App Name**: FiscalFlow Pro

## Core Features:

- Sticky Navigation with Anchors: Implement a responsive, sticky navigation bar with anchor links to smoothly navigate between different sections of the landing page.
- Hero Section Design: Create an engaging hero section to capture user attention and clearly present the 'Gestión Fiscal Digital para PyMEs' service.
- Key Features Display: Showcase the core features and benefits of the digital tax management service in an easy-to-understand format.
- Contact Form: Integrate a functional contact form allowing potential clients to inquire about the service.
- Language Toggle (ES/EN): Add a JavaScript-powered toggle to switch the entire page content between Spanish and English.
- Dark Mode Toggle: Include a JavaScript function to toggle Tailwind CSS's 'dark' class, enabling users to switch between light and dark themes.

## Style Guidelines:

- Light Mode Primary: A bold Indigo (#6366F1) for calls to action, conveying trust and innovation. (HSL: H 238, S 89%, L 66%)
- Light Mode Background: Clean White (#FFFFFF) to provide a spacious and professional feel. (HSL: H 0, S 0%, L 100%)
- Light Mode Accent/Containers: An extremely subtle cool-gray (#F8FAFC) for container backgrounds, maintaining visual harmony. (HSL: H 210, S 33%, L 98%)
- Dark Mode Primary: A vibrant, slightly lighter Indigo (#818CF8) for CTAs, ensuring visibility against the dark background. (HSL: H 238, S 90%, L 74%)
- Dark Mode Background: A deep, professional Charcoal-Blue (#0F172A) for a modern, focused user experience. (HSL: H 220, S 52%, L 11%)
- Dark Mode Accent/Containers: A subtle Dark Blue-Gray (#1E293B) for containers, creating depth without distraction. (HSL: H 213, S 37%, L 17%)
- Headline and Body Font: 'Inter', a grotesque sans-serif, offering a modern, objective, and highly legible appearance suitable for a professional digital service.
- Utilize modern, clean line-style icons for feature highlights and navigation elements to enhance the professional and digital aesthetic.
- Employ a responsive, section-based layout with clear hierarchy, ensuring readability and ease of navigation across all device sizes. Focus on prominent CTAs.
- Subtle and smooth transitions for navigation scrolling, language changes, and the dark mode toggle to enhance user experience without being distracting.
