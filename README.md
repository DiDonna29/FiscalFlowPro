# FiscalFlow Pro - Gestión Fiscal Digital para PyMEs

FiscalFlow Pro es una solución integral de software como servicio (SaaS) diseñada específicamente para pequeñas y medianas empresas (PyMEs) y trabajadores independientes que buscan automatizar sus procesos contables y tributarios.

## 🚀 Propósito de la Aplicación
La aplicación sirve como el punto de entrada principal (Landing Page) para un ecosistema de herramientas financieras. Permite a los usuarios:
- Visualizar soluciones de automatización fiscal.
- Gestionar su facturación electrónica de manera simplificada.
- Acceder a reportes en tiempo real sobre la salud financiera de su negocio.
- Contactar con consultores especializados directamente desde la plataforma.

## 🛠️ Stack Tecnológico
- **Frontend**: Next.js 15 (App Router), React 19.
- **Estilos**: Tailwind CSS con sistema de diseño basado en Shadcn UI.
- **Iconografía**: Lucide React.
- **Internacionalización**: Context API personalizada para soporte bilingüe (EN/ES).
- **Tema**: Soporte nativo para Modo Claro y Oscuro.

## 📦 Instalación y Ejecución

La aplicación está configurada para funcionar sin problemas con los principales gestores de paquetes:

### Con NPM
```bash
npm install
npm run dev
```

### Con Yarn
```bash
yarn install
yarn dev
```

### Con PNPM
```bash
pnpm install
pnpm dev
```

## 🧠 Lógica de Desarrollo
- **Responsive-First**: Diseñado con un enfoque móvil primero, escalando hasta monitores ultra-wide.
- **Anti-Overflow**: Implementación de seguridad en contenedores para evitar que datos numéricos largos o cadenas de texto rompan la interfaz.
- **SEO & Performance**: Estructura semántica para mejor indexación y uso de fuentes optimizadas.

## 🔮 Futuro Escalable (Roadmap)
1. **Módulo de Dashboard Real**: Integración con Firebase Firestore para mostrar métricas reales del usuario.
2. **Generador de Facturas PDF**: Capacidad de exportar comprobantes legales directamente desde el navegador.

4. **API de Pasarela de Pagos**: Conexión con Stripe o PayPal para gestionar cobros de servicios recurrentes.
